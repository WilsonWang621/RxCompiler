## 当前实现边界

`--stage semantic` 当前执行解析、AST 构建和 AST 输出。名称解析、常量求值、类型检查及代码生成尚未实现；构建出 AST 只说明这一阶段成功。

值表达式中的路径构建目前支持单段普通标识符。字段访问和方法调用的 `dotSuffix` 仍未接入，表达式 `()` 也仍未支持。类型中的 `()` 已支持，两者属于不同语法入口。

`tests/` 保留在本地，已从 Git 跟踪中移除并加入 `.gitignore`。文档中的测试命令需要本地已有这些测试文件。

## 后续记录方式

遇到新的问题或提问，按主题追加到对应文档；已有问题有新结论时更新原条目，保留有价值的失败尝试。

- 问题记录写清楚：触发样例、实际表现、原因、修复、验证。
- 设计记录写清楚：原来的限制、现在的表示、为什么这样做、相关函数。
- 问答记录保留提问含义，直接给出结论，再用一个小例子解释。
- 只把复现过或能从提交确认的问题记为错误；疑问、建议和阶段性限制分别说明。
- 测试结果注明对应阶段，不把 AST 测试通过写成语义分析或代码生成通过。
